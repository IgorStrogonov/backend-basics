# City Summary CLI

Утилита для получения сводки по городу: текущая погода и курс выбранной валюты к рублю.

Проект демонстрирует работу с внешними API (Open-Meteo и Frankfurter), обработку сетевых ошибок (timeout, retry), валидацию ответов и разделение логики на слои.

## Требования

- Python 3.10 или выше
- Менеджер пакетов `pip`
- Доступ в интернет (для запросов к внешним API)

## Запуск

Базовый запуск (город Москва, валюта USD по умолчанию):
   ```bash
   python main.py --city Moscow
   ```
Запуск с указанием другой валюты (например, евро):
   ```bash
   python main.py --city Moscow --currency EUR
   ```
Запуск с выводом результата в формате JSON:
  ```bash
   python main.py --city Moscow --json
   ```

## Пример вывода: 
  ```bash
  Город: Moscow
  Погода: 8.4°C, overcast
  Тёплая одежда: нет
  Зонт: нет
  USD → RUB: 80.78
  Дорогой курс: нет
  Дешёвый курс: нет
   ```
