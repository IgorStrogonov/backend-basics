# Library API - OpenAPI Contract

Этот репозиторий содержит спецификацию OpenAPI 3.1 для сервиса «Библиотека». 
Сервис позволяет управлять книгами, читателями и выдачами книг.

## Стек и инструменты
- Спецификация: **OpenAPI 3.1.0**
- Формат описания: **YAML**

## Структура проекта
- `openapi.yaml` — основной файл спецификации API.
- `STYLE.md` — правила оформления и проектирования API.
- `REVIEW.md` — саморевью контракта по чек-листу.
- `README.md` — описание проекта (этот файл).

## Как просмотреть документацию (Swagger UI)

Чтобы увидеть интерактивную документацию, выполните следующие шаги:
1. Перейдите на сайт [Swagger Editor](https://editor.swagger.io/).
2. Скопируйте содержимое файла `openapi.yaml`.
3. Вставьте его в левую панель редактора на сайте.
4. Справа отобразится интерактивная документация (Swagger UI), где можно ознакомиться с эндпоинтами, схемами данных и примерами запросов/ответов.

## Особенности API
- **Версионирование:** Все эндпоинты находятся по пути `/v1/`.
- **Безопасность:** Поддерживается Bearer JWT (см. `securitySchemes` в спецификации). Метод `POST /books` защищен.
- **Идемпотентность:** Метод `POST /loans` требует заголовок `Idempotency-Key` для защиты от дублирования выдач (TTL 24 часа, обработка mismatch).
- **Бизнес-правила:** Валидация доступных копий (`available_copies`), лимит выдач на читателя, запрет на удаление активных сущностей — все правила описаны в спецификации.
- **Единый формат ошибок:** Все ошибки возвращаются в формате `ErrorResponse` с машиночитаемым кодом (например, `VALIDATION_ERROR`, `NOT_FOUND`, `CONFLICT`).
- **Примеры:** В спецификацию добавлены примеры успешных ответов и типичных ошибок (404, 409, 422) для наглядности.
